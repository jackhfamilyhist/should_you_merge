# should_you_merge
Simple python software of my design. Made to give a confidence percentage on whether or not data matches the same person in family history work based on a handful of questions. Fairly up front about assumptions, now does record or access any data outside of current session but only within its folder with certain files that come with it. It uses a lot of math to justify its conclusion.
Anyways, main issue is when there are clumps of similarly named people in a small area.
